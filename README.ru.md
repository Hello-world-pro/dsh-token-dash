# dsh-token-dash 🇷🇺 — русская локализация (fork)

Русская локализация плагина **DSH Token 看板** — форк
[spartawhy117/dsh-token-dash](https://github.com/spartawhy117/dsh-token-dash).

> **Что важно знать сразу:** это самостоятельный форк. Оригинальный репозиторий, его код,
> релизы и npm-пакет **не изменяются**. Открытых pull request в апстрим нет, issue там не
> создаются, автор оригинала не тегается. Связь с оригиналом — только стандартная пометка
> GitHub «forked from».

## Что это

Плагин показывает расход на модели за сегодня, остаток месячного бюджета и окна подписок
по семи провайдерам прямо рядом с полем ввода DSH. Ключи определяются автоматически,
стоимость и Tokens считаются локально, данные за месяц можно экспортировать и импортировать.

В этом форке интерфейс дополнительно переведён на русский язык.

## Что добавлено относительно оригинала

- Русский словарь интерфейса (`RU`, 139 ключей) рядом со штатными `ZH` / `EN`.
- Пять недостающих ключей английского словаря — английский интерфейс больше не откатывается
  к китайским ключам.
- Регистрация `ru` вынесена в отдельный эффект: если внешний русский языковой пак уже занял
  пространство имён `ru`, форк уступает ему и не ломает привязанный переводчик.
- Запись в `CHANGELOG.md` о русской локализации.

Всё остальное — расчёты, провайдеры, вёрстка, логика обновлений — взято из оригинала без
изменений.

## Почему это форк, а не pull request

PR с русским словарём был отправлен в оригинальный репозиторий и закрыт автором: словарь он
принял как полезный референс, но указал, что сначала нужен отдельный проход по вёрстке под
длинные строки — гибкие ширины, правила переноса, проверка на узкой ширине и при 200 %
масштабировании текста. Этот форк — место, где русская локализация живёт до тех пор, пока
такой проход не появится в апстриме.

## Установка

Да, форк ставится ровно так же, как любой другой плагин DSH — командой `dsh plugin add`.
Она является обёрткой над pnpm в каталоге профиля, поэтому в качестве источника принимает
локальный путь, git-репозиторий или npm-пакет.

```powershell
dsh plugin --profile desktop add <источник>
```

`desktop` — имя профиля; если у вас другой, подставьте его.

### Вариант 1. Прямо из GitHub (нужен установленный git)

```powershell
dsh plugin --profile desktop add github:Hello-world-pro/dsh-token-dash#feat/ru-locale
```

`#feat/ru-locale` указывать нужно явно: русская версия живёт в этой ветке, а спецификатор
`github:` без суффикса возьмёт ветку по умолчанию, что менее предсказуемо.

### Вариант 2. Из локальной копии (git не требуется)

1. Откройте [страницу ветки](https://github.com/Hello-world-pro/dsh-token-dash/tree/feat/ru-locale)
   и скачайте архив: **Code → Download ZIP**.
2. Распакуйте, например в `C:\dsh-token-dash-ru`.
3. Добавьте распакованный каталог:

   ```powershell
   dsh plugin --profile desktop add "C:\dsh-token-dash-ru\dsh-token-dash-feat-ru-locale"
   ```

Если репозиторий уже склонирован (ветка `feat/ru-locale`), укажите путь к клону:

```powershell
dsh plugin --profile desktop add "C:\путь\к\dsh-token-dash"
```

### Чего делать не нужно

`dsh plugin --profile desktop add dsh-token-dash` поставит **оригинальный** пакет автора из
npm — без русского словаря. Форк в npm не публикуется, поэтому имя пакета как источник здесь
не подходит.

### Если плагин уже был установлен

Сначала уберите прежнюю версию, затем добавьте форк:

```powershell
dsh plugin --profile desktop remove dsh-token-dash
dsh plugin --profile desktop add "C:\путь\к\dsh-token-dash"
```

### После установки

Язык интерфейса берётся из локали DSH: при `ru` показывается русский словарь, при `zh` или
`en` — соответствующий штатный. Перезагрузите плагин или приложение DSH, чтобы изменения
вступили в силу.

Проверить, что подхватился именно форк:

```powershell
dsh plugin --profile desktop why dsh-token-dash
```
