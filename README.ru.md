# dsh-token-dash 🇷🇺 — русская локализация (fork)

Русская локализация плагина **DSH Token 看板** — форк
[spartawhy117/dsh-token-dash](https://github.com/spartawhy117/dsh-token-dash).

> **Что важно знать сразу:** это самостоятельный форк. Оригинальный репозиторий, его код,
> релизы и npm-пакет **не изменяются**. Открытых pull request в апстрим нет, issue там не
> создаются, автор оригинала не тегается. Связь с оригиналом — только стандартная пометка
> GitHub «forked from».

## Что это

Плагин показывает расход на модели за сегодня, остаток месячного бюджета и окна подписок
по семи провайдерам прямо рядом с полем ввода DSH. Ключи определяются автоматически,
стоимость и Tokens считаются локально, данные за месяц можно экспортировать и импортировать.

В этом форке интерфейс дополнительно переведён на русский язык.

## Что добавлено относительно оригинала

- Русский словарь интерфейса (`RU`, 139 ключей) рядом со штатными `ZH` / `EN`.
- Пять недостающих ключей английского словаря — английский интерфейс больше не откатывается
  к китайским ключам.
- Регистрация `ru` вынесена в отдельный эффект: если внешний русский языковой пак уже занял
  пространство имён `ru`, форк уступает ему и не ломает привязанный переводчик.
- Запись в `CHANGELOG.md` о русской локализации.

Всё остальное — расчёты, провайдеры, вёрстка, логика обновлений — взято из оригинала без
изменений.

## Почему это форк, а не pull request

PR с русским словарём был отправлен в оригинальный репозиторий и закрыт автором: словарь он
принял как полезный референс, но указал, что сначала нужен отдельный проход по вёрстке под
длинные строки — гибкие ширины, правила переноса, проверка на узкой ширине и при 200 %
масштабировании текста. Этот форк — место, где русская локализация живёт до тех пор, пока
такой проход не появится в апстриме.

## Установка

1. Клонируйте форк и перейдите на ветку `feat/ru-locale` (она же ветка по умолчанию):

   ```powershell
   git clone https://github.com/Hello-world-pro/dsh-token-dash.git
   cd dsh-token-dash
   git checkout feat/ru-locale
   ```

2. Установите пакет в DSH как обычный плагин:

   ```powershell
   dsh plugin --profile desktop add <абсолютный путь к клонированному каталогу>
   ```

3. Язык интерфейса берётся из локали DSH. Русский словарь активируется, когда хост-локаль
   приложения — `ru`; при `zh` или `en` показывается соответствующий штатный словарь.

После установки перезагрузите плагин или приложение DSH.
