## 十、QuotaGauge 控件要求（P3 订阅专用）

> 与 P1 明确分开：现有 `ProgressRing` 只画几何，P1 继续「环 + 右侧数字」内联；P3 新增组合层 `QuotaGauge`，单独承接「环心标签 + 环下数值」排版，不复用 P1 样式。

### 10.1 签名

```js
QuotaGauge({
  label,          // '5h' / '周' / '月'，渲染在环心
  percent,        // 0–100；null → 空环 + '—'
  state,          // 'normal' | 'critical' | 'empty'（调用方按 ≥90 判定）
  remaining,      // 已格式化，如 '剩余 58%'
  relative,       // '3 小时后'
  absolute,       // '22:51'
  size = 40,
  stroke = 4,
})
```

### 10.2 结构与尺寸

```text
┌ 环 40 × 40（stroke 4，中间透明）
│   └ 环心：label 12px / 500 / label-tertiary
├ 间距 3px
├ percent 16px / 600（normal 蓝 / critical 红 / empty 弱）
├ 间距 4px
├ remaining 11px / tertiary
├ relative 11px / tertiary
└ absolute 11px / tertiary
```

- 容器 `display:flex; flex-direction:column; align-items:center; gap:4px; min-width:0`。
- 文本 `white-space:nowrap`；列宽 61px 时 `剩余 58%` 与 `22:51` 均不换行。

### 10.3 状态与配色

| 状态 | 弧 | 百分比 | 环心标签 | 辅助行 |
|---|---|---|---|---|
| normal | `label-primary` | `business-primary` 蓝 | tertiary（**不随状态变色**） | tertiary |
| critical（≥90） | `state-error-primary` | 红 | 同上 | tertiary |
| empty | 不画弧（仅轨道） | `—` | 同上 | `—` 或整块只留百分比 |

- 轨道 `border-l3`；零 hex；中心标签不参与告警色，避免整块糊红。
- 空态只在 `percent` 为 `null` 时出现；窗口缺失不渲染列，不产生空态列。

### 10.4 卡内约束

- 卡 229px → 内容 199px；窗口列宽 3 窗 61 / 2 窗 96 / 1 窗 199。
- 环 40 在 61px 列内左右各留约 10px；`42.5%` 16px 约 42px，不换行。
- 窗口数 = `provider.windows.length`（1–3），不补空列；卡内顺序为「名称行 → 10px → 窗口行」。

### 10.5 无障碍

- 外层 `role="group"`，`aria-label` 形如 `5h 已用 42.5%，剩余 58%，3 小时后重置`；SVG `aria-hidden`。
- 空态 `aria-label` 形如 `5h 暂无数据`。
- 百分比不是唯一载体：剩余% 与时间同时可读。

- P2 的 `WindowRow` 继续用 `ProgressRing` 内联（P2 不放环心标签）。
- E2E：`token-dash-quota-gauge-<providerId>-<key>`，断言环 40、中心文字为周期、百分比在环下。
