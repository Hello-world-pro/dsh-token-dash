# Token 看板 UI 设计

> 唯一 UI 设计真源：视觉、信息层级、文案与交互以本文件为准。<br>
> **当前版本：v2（2026-11-02 UI 迭代定稿，待实施）**——双 tab + 时间范围 + cc-switch 托盘面板语言；v1（已发布 1.0.x）与 v2 的差异见 §9 变更记录。<br>
> 架构与数据流见 [design.md](design.md)；本轮迭代的需求与实施细节见 [UI 迭代计划](plan/active/feature_ui_refresh.md)。

## 1. 定位与信息层级

| 层 | 回答的问题 | 只放什么 |
|---|---|---|
| P1 Pill | 现在怎样？ | 当前 provider 的模式、预算 %、今日、余额（订阅为窗口 %） |
| P2 用量 tab | 钱花在哪（范围）？ | 固定区（本月预算/订阅）+ 范围区（两格卡 + 明细行卡片） |
| P3 设置 tab | 怎么配？ | 预算、显示、日志、价格链接、更新 |

不重复原则：同一事实只在一个层级承担"主展示"；下层补增量，不原样复读。v2 起 P2/P3 收进同一浮层的 `用量 / 设置` 双 tab（用量在前，默认）。

| 信息 | P1 | P2 用量 | P3 设置 |
|---|---|---|---|
| 当前 provider 名称 | 否（只有模式徽标） | 是（组行） | 是 |
| 预算 % / 已用总额 | % | 已用/总额 + % + 迷你条 | 输入总额 |
| 今日消耗 | 是 | 否（范围卡替代"今日"概念；当天范围即今日） | 否 |
| 账户余额 | 是（开关控制） | 是（固定区预算行右端） | 开关 |
| 范围费用 / Tokens | 否 | 两格卡 + 明细（范围） | 否 |
| 按模型明细 | 否 | 行卡片（范围） | 否 |
| 订阅窗口 | 是（当前） | 固定区（全部，QuotaBlock） | 同款 QuotaBlock |

## 2. 全局视觉（v2：cc-switch 托盘面板语言）

| 项 | 规格 |
|---|---|
| 面板宽 | **320**（cc-switch 同款）；浮层贴 pill 正上方、左对齐、间距 8px、允许遮挡；最大高 70vh 内部滚动 |
| 字号阶梯 | 行名/组行 13px / 600；副行、小标、标签 10.5–11px muted；大数字 17px / 600；全部 `tabular-nums` |
| 主色 | `var(--dsw-alias-state-business-primary, #6ea8ff)` |
| 警告 / 超支 | `#f0a020` / `#e05a5a`；金额强调 green |
| 色彩纪律 | 蓝仅选中/主状态、amber 警告、green 金额、红超支；**其余全部灰阶** |
| 进度条 | h **4px** 圆角满、行内（不是满宽独立行）；轨道 `bg-black/10`；填充按状态色；min 宽 24px 随网格弹性 |
| 布局网格 | 信息行三列 `[minmax(0,1fr) auto auto]`：主内容左、控件组右缘锚定（右缘 12px padding 线） |
| 行高 / 间距 | 信息行 py 6px；组间 gap 10px；区内行间 gap 2px；面板 padding 12 |
| 分隔线 | 1px `bg-black/[0.08]`、左右缩进 8px、上下 margin 6px |
| segmented | 胶囊：容器 `bg-black/[0.06]` + p 0.5、选中白底 + shadow-sm、11px |
| 圆角 | Pill 999；卡片 10；浮层 12；控件 6 |
| 主题 | 跟随宿主 CSS 变量，必须给回退值；不写死亮 / 暗 |
| 焦点 | `focus-visible:ring-2 ring-blue-500/60`；Tab 顺序 = 视觉顺序 |
| 动效 | 非必要不加；`prefers-reduced-motion` 下关闭 |

预算状态不能只靠颜色：百分比数字 + 状态色 + 文案共同表达。

## 3. P1 Pill（v2 不变）

```text
API    [API] 预算 25.4% · 今日 ¥11.37 · 余额 ¥8.74⌃
订阅   [订阅] 5h 42% · 周 18%⌃
```

- 两处槽位：首页工作区行；会话活动行左侧。都不撑开输入框。
- 只画 API / 订阅两态；判定不了默认 `[API]`；不显示 provider 名（hover title / aria-label 兜底）。
- API 段：预算 %（未设置显示"未设置"）· 今日 · 余额；金额按 provider 币种。
- 订阅段：5h/周窗口 + 重置时间；百分比是账户套餐，不拆单对话。
- 预算色：<80% 主色、80–100% 橙、≥100% 红；无数据 `--`，过期加 `~`。
- 尺寸：高 24、圆角 999、水平 padding 8、段间距 6；Enter/Space 展开，`aria-expanded` 同步。

## 4. P2 用量 tab（v2）

### 4.1 结构

```text
┌──────────────────────────────────────────────┐
│ 用量 · 设置（segmented 胶囊）          ⟳     │  ← 标题+tab 一行；关闭靠点击外部
│                                              │
│ 本月预算                                     │  ← 小标 10.5px 灰
│ DeepSeek    ¥12.68/¥50.00 25% ▓▓░  余额¥8.74 │  ← 预算行 + 右端账户余额
│ 订阅套餐（账户级）                  [重新检测] │
│ GLM Coding  5h 42% ▓▓░  周 18% ░  14:05 重置 │  ← QuotaBlock 网格
│ ──────────────────────────────────────────  │  ← 1px 分隔线，左右缩进
│ [当天|7天|30天|全部]                         │  ← 范围 segmented 11px
│ ┌─ 总费用 ──────┐ ┌─ 真实 Tokens ─────────┐ │
│ │ ¥12.68        │ │ 319.4M                │ │  ← 值 17px + detail 10.5px
│ │ $19.00        │ │ 入 1.88M · 出 1.12M   │ │
│ └───────────────┘ └───────────────────────┘ │
│ DeepSeek                                    │  ← provider 组行 13px semibold
│   DeepSeek-V4.1-Flash            319.4M ⓘ  │  ← 模型行（缩进 12px）+ tooltip
│     1.08k 请求 · 99.4% 命中 · ¥12.68        │  ← 副行 10.5px 灰
│ Qwen（百炼）                                 │
│   qwen3.8-max                     8.2M ⓘ   │
│     24 请求 · 91.0% 命中 · ¥0.02            │
│ 本机估算 · 刚刚                             │  ← 底注 10.5px
└──────────────────────────────────────────────┘
```

### 4.2 固定区（不随范围变）

- **本月预算**：每 API provider 一行——`名称 | 已用/总额（11px）| % + 4px 迷你条 | 余额（右端，11px）`；超支红；无预算"预算未设置"+ 满格中性条；余额为账户余额（#31 定案：P2 恒显示，不受 P1 开关影响；Qwen 等不支持显示"—"）。
- **订阅套餐（账户级）**：每订阅 provider 一行 QuotaBlock 网格（`5h 42% ▓▓░ · 周 18% ░ · 14:05 重置`，三列：文字 11px | 迷你条 4px | 重置 10.5px）；标题行右侧一个"重新检测"（只重查订阅）；空窗口"套餐查询失败"。
- 固定区与范围区用 1px 分隔线分离；文案带"本月"防口径混读。
- 标题栏 `⟳` 刷新：重新拉取 `/summary`（固定区）与 `/usage`（范围区，带当前 range）；进行中禁用态。

### 4.3 范围区（随范围变）

- 范围 segmented：`当天 / 近7天 / 近30天 / 全部`，默认当天，本地记忆。
- **两格卡**：总费用（多币种分行）+ 真实 Tokens（detail：入/出）；只统计范围内有消耗的 provider/model；无消耗 `¥0.00`。
- **明细行卡片**（合并原费用表+用量表）：provider 组行（13px semibold）→ 模型行缩进 12px（名称 + 右对齐 Tokens 总量 + `ⓘ`）→ 副行 10.5px（`请求 · 命中率 · 费用`）。
  - `ⓘ` tooltip：`输入 1.88M · 缓存 316.39M · 输出 1.12M`（tabular-nums）——零宽度成本。
  - 只列范围内有消耗的行；不补"配置即可见"默认行；无表头无列宽（天然适配 320）。
  - 费用按 provider 币种（provider 币种唯一，无跨币种行）；订阅 token 计入用量、费用不显示。

## 5. P3 设置 tab（v2）

```text
┌──────────────────────────────────────────────┐
│ 用量 · 设置（segmented）          ⟳          │
│ API 计费（已检测 2）                         │
│ DeepSeek      预算 [ 50.00 ]  CNY           │
│ OpenRouter    预算 [ 20.00 ]  USD            │
│ 订阅（账户级，已检测 2）      [重新检测]     │
│ GLM Coding                                   │
│   5h 42% ▓▓░   周 18% ░   重置 14:05        │  ← 与 P2 同款 QuotaBlock
│ Kimi Coding                                  │
│   5h 30% ▓▓░   周 12% ░   重置 15:20        │
│ 显示                                         │
│ 刷新间隔      [30秒|1分钟|5分钟]             │
│ 账户余额                                 ⬤  │
│ 日志                                         │
│ [打开日志文件夹]   [导出日志]                │
│ 价格与版本                       [检查更新]  │
│ 版本 1.0.2 · 已保存                          │  ← 状态行（aria-live）
└──────────────────────────────────────────────┘
```

### P3 显示细节

| 项 | 规格 |
|---|---|
| API 预算行 | 名称 13px 左；右侧组 = `预算` 11px 灰 + input（宽 72px、右对齐、tabular-nums、`bg-black/[0.05]` 圆角 6、失焦/Enter 保存）+ 币种 11px 灰 |
| 订阅行 | provider 名 13px semibold + QuotaBlock 副行（**与 P2 完全同款**） |
| 刷新间隔 | 三段 segmented（同 tab 胶囊样式） |
| 账户余额 | label 13px 左 + toggle 右（28×16、选中蓝） |
| 状态行 | `版本 X.Y.Z · 已保存`——`已保存/失败` 11px（失败红）、`aria-live=polite`、**固定高度占位**（空态保留行高不跳动）；检查更新全流程状态在此演进（`检查中… → 已是最新 / 发现 X.Y.Z [更新] → 已更新，重启生效`） |
| 日志按钮 | 两枚并排（`bg-black/[0.05]` 圆角 6、11px、图标+文字） |
| 小标（分区标题） | 10.5px 灰、上下 margin 4px 贴紧内容、带计数 `(已检测 N)`；右侧可挂动作按钮（重新检测/检查更新，11px） |

- 更新：发现新版本 → 确认 → 安装；成功"已更新到 X.Y.Z，重启 DSH 后生效"，失败显示原因并可复制命令；不静默更新。
- 日志：只有打开固定目录 + 导出脱敏 `.log`；不自动上传。

## 6. 交互与可访问性

- Pill：`role=button`、`tabIndex=0`、Enter/Space、`aria-expanded`、完整 aria-label。
- Panel：`role=dialog`；tab 用 `role=tablist/tab`，范围选择器用 `role=tablist`；键盘可完成全部切换。
- 关闭走点击外部（v2 起无关闭按钮）；Esc 不处理（D-15）；关闭后尽力归还焦点。
- tooltip（`ⓘ`）：`aria-describedby` 关联；触屏/无 hover 时点按也展示。
- 对比度正文 ≥4.5:1；预算状态不只靠颜色。
- i18n 预留 `zh` / `en`，命名空间 `token-dash.*`；用占位符拼装，不拼整句。

## 7. 文案与空态

| 场景 | 文案 |
|---|---|
| 无预算 | `预算 未设置` |
| 预算行 | `¥12.68 / ¥50.00  25%` |
| 订阅失败 | `套餐查询失败` |
| 未定价 | `未定价`（近似价加 `≈`） |
| 空明细 | 组行/模型行不渲染；两格卡显示 `¥0.00` |
| 空订阅 | 订阅段整体隐藏 |
| 更新成功 | `已更新到 X.Y.Z，重启 DSH 后生效` |
| 更新失败 | `更新失败（原因）` + 复制命令 |

金额按 provider 币种格式化；不跨币种合计；没有分母就不显示百分比。

## 8. 明确不做

- 不做 OS 悬浮窗、右下角挂件、显示位置设置。
- 不做趋势图、热力图、请求日志页、逐条明细（v2 范围决策 D-09）。
- 不做价格编辑、汇率换算、自定义币种。
- 不做日志自动上传。
- 不做"查看全部"/独立明细页/分页（BND-02）。
