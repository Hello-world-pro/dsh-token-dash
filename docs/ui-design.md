## 1. 定位与信息层级

| 层 | 回答的问题 | 只放什么 |
|---|---|---|
| P1 Pill | 现在怎样？ | 当前 provider 的模式、预算 %、今日、余额（订阅为窗口 %） |
| P2 用量 tab | 钱花在哪（范围）？ | 固定区（本月预算/订阅）+ 范围区（两格卡 + 明细行卡片） |
| P3 设置 tab | 怎么配？ | 预算、显示、日志、价格链接、更新 |

不重复原则：同一事实只在一个层级承担"主展示"；下层补增量，不原样复读。v2 起 P2/P3 收进同一浮层的 `用量 / 设置` 双 tab（用量在前，默认）。

| 信息 | P1 | P2 用量 | P3 设置 |
|---|---|---|---|
| 当前 provider 名称 | 否（只有模式徽标） | 是（组行） | 是 |
| 预算 % / 已用总额 | % | % + 迷你条 + 已用/总额 | 输入总额 |
| 今日消耗 | 是 | 否（范围卡替代"今日"概念；当天范围即今日） | 否 |
| 账户余额 | 是（开关控制） | 是（固定区预算行右端） | 开关 |
| 范围费用 / Tokens | 否 | 两格卡 + 明细（范围） | 否 |
| 按模型明细 | 否 | 行卡片（范围） | 否 |
| 订阅窗口 | 是（当前） | 固定区（全部，QuotaBlock） | 同款 QuotaBlock |

## 3. P1 Pill

```text
API    [API] 预算 25.4% · 今日 ¥11.37 · 余额 ¥8.74⌃
订阅   [订阅] 5h 42% · 周 18%⌃
```

- 两处槽位：首页工作区行；会话活动行左侧。都不撑开输入框。
- 只画 API / 订阅两态；判定不了默认 `[API]`；不显示 provider 名（hover title / aria-label 兜底）；无任何 provider 时显示 `[API] --`，不隐藏 Pill。
- API 段：预算 %（未设置显示"未设置"）· 今日 · 余额；金额按 provider 币种。
- 订阅段：5h/周窗口 + 重置时间；百分比是账户套餐，不拆单对话。
- 预算色：<80% 主色、80–100% 橙、≥100% 红；无数据 `--`，过期加 `~`。
- 尺寸：高 24、圆角 999、水平 padding 8、段间距 6；Enter/Space 展开，`aria-expanded` 同步。
- 加载：保留上次值；无上次值时预算/窗口 `--`，不显示 0%。
- 刷新失败/无 provider：显示 `[API] --` 或 `[订阅] --`，不隐藏 Pill；不弹出 toast。
- stale：上次成功超过 2 个刷新周期，数值后加 `~`；颜色不变。

### 4.2 固定区（不随范围变）

- 固定区整体一块 **section 底框**（低对比中性灰，圆角 10）；预算/订阅行在内部透明，不再逐行加卡框；两个小标都带动态 `(已检测 N)`。
- 只渲染 `summary.providers` 中实际存在的 API/订阅 provider；某区为 0 时隐藏该区，不显示空标题。
- 固定区所有条统一用一个 **MiniBar**：48×4、圆角满、轨道灰、填充主蓝；预算 % 一条、订阅每个窗口各一条；同一行多条也全部同规格，不做粗细/长短/颜色变体。
- **本月预算**：每 API provider 两行——首行是**名称行四列**：`名称（弹性）| %（34px）| 已用/总额（弹性）| 余额（72px）`，四列跨 provider 左缘对齐；次行是**满宽迷你条**（`height:4`、`width:100%`、圆角 999，填充主蓝），让 8% 与 92% 的差距一眼可见。满宽条是 `MiniBar` 的 `stretch` 变体，**仅预算行使用**，订阅窗口仍为 48×4。超支只改百分比文字颜色；无预算"未设置"+ 满格中性条；余额为账户余额（#31：P2 恒显示，Qwen 等不支持显示"—"）。
- **订阅套餐（账户级）**：每个订阅 provider 两行——首行 `名称（12px） … 重置时间（10.5px，右端锚定）`，重置文案由标准组件 `ResetLabel` 渲染：`x 小时后 · MM-DD HH:mm 重置`，单位规则为 **<1 小时用「x 分钟后」（取整、最小 1 分钟、不显示秒），1–24 小时用「x 小时后」，≥24 小时用「x 天后」**，绝对时间固定带日期；次行 `5h 42% ▓▓░` 与 `周 18% ░` 两组**左右分开**，最后一组的迷你条右端与分区内容右边界对齐（`justify-content: space-between`，条宽仍固定 48×4，不拉伸）；两组百分比文字固定 34px 宽，保证 5h 与 周 的标签、条在不同 provider 之间**列对齐**；标题行右侧只放 `⟳` 图标按钮（只重查订阅）；空窗口"套餐查询失败"。
- 订阅区 `⟳` 为 14px `RefreshCw` 图标、22×22 点击区、默认蓝按钮底、无文字；`aria-label="重新检测订阅配额"`，hover/focus 显示同名 tooltip；点击后图标旋转并禁用，不显示“检测中…”文字。
- 标题栏 `⟳` 是全局刷新（`/summary` + `/usage`），订阅区 `⟳` 是局部刷新；两者同图标，靠位置和 tooltip 区分，不靠文字。
- 固定区与范围区用 1px 分隔线分离；文案带"本月"防口径混读。
- P2 不显示底部“本机估算 / 刷新时间”底注；刷新状态只由标题栏 `⟳`（进行中禁用）表达。
- 标题栏固定 `ⓘ` 支持范围 + `⟳` 刷新 + `×` 关闭：`⟳` 重新拉取 `/summary`（固定区）与 `/usage`（范围区，带当前 range），进行中禁用；`×` 必须始终可见，点击关闭浮层。
- `ⓘ` 只在 P2 用量 tab 出现，位于 `⟳` 左侧；12px 图标、22×22 点击区、默认蓝按钮底（同 §2 按钮）；hover / focus / 触屏点按显示 tooltip：
  `目前支持 DeepSeek / Kimi / GLM / OpenRouter / Qwen API Key`
- tooltip 最大宽 220px、11px、两行内换行；不占常驻行，不改变头部高度；键盘可聚焦，`aria-describedby` 关联。

### 4.3 范围区（随范围变）

- 范围选择器就是顶部 tab 同款 **segmented 胶囊**：`当天 / 近7天 / 近30天 / 全部`，默认当天、**不做本地记忆**（每次打开回到当天）；尺寸和主题 token 见 §2；不是普通 tab / 下划线。
- 范围区整体一块 **section 底框**；两格统计卡用更深一层的 **tile 底框**（`color-mix(in srgb, var(--dsw-alias-label-primary) 4%, transparent)`），明细行保持透明，只靠间距和 hover 区分。
- **两格卡**：`rangeCard` 两列（`grid-template-columns:1fr 1fr`、gap 8）；`总费用` 与 `真实 Tokens` 各自是独立 `tile` 底框（背景 + 圆角 + padding），不得退化为两行纯文本；总费用多币种分行、金额用**主蓝（accent）**而非绿色，**不显示「按币种」说明行**；真实 Tokens 标题右侧唯一 `ⓘ`，副行只放三个数字（输入 · 缓存 · 输出，**不带中文标签**，顺序由 tooltip 解释）；只统计范围内有消耗的 provider/model；无消耗 `¥0.00`。
- **两格卡口径**：两者取同一模型集合。总费用 = Σ 计费模型费用（按币种，订阅模型计 0 且明细不显示费用）；真实 Tokens = Σ 全部模型 `tokens.total`，含输入 / 缓存读 / 缓存写 / 输出。缓存数值一律为 `cacheRead + cacheWrite`，明细括号与副行同口径，三数之和等于总数。
- **数据来源**：两格卡与副行的数值全部来自 VM（`usage.totals` / `usage.total` / `usage.models[].tokens`），UI 不做求和；`total` 含全部已使用模型，订阅模型也计入 Tokens。
- **字号（按代码）**：tile 标签 11px、主值 17px（总费用行 14px）、副行 10.5px；明细组名 13px semibold、模型名 12px、费用 11px；用量行标签 9.5px、数值 10.5px/600。
- **明细行卡片**（合并原费用表+用量表）：provider 组行（13px semibold）→ 模型行（名称左 + 费用右）→ 用量单行（Tokens + 请求 + 命中）。
  - 费用是主比较指标：模型行右侧右对齐，`tabular-nums`；`未定价` 用 muted，近似价加 `≈`。
  - 模型行不再放逐行 `ⓘ`；用量固定**一行**：`Tokens 12.5k [12.3k/0/195]` + `请求 1` + `命中 0%`；括号内按输入/缓存/输出顺序，只放数值；标签 9.5px muted、数值 10.5px / 600 `tabular-nums`；空间不足时仅压缩 Tokens 前缀/bracket，请求与命中不换行。
  - 唯一说明图标在 `真实 Tokens` 标题右侧；tooltip 只写 `Tokens 括号顺序：输入 / 缓存（读+写）/ 输出`，不重复数值，不放到每个模型行。
  - 订阅 provider 不显示费用（右侧留空），用量仍保留；API 费用按 provider 币种，不跨币种。
  - 只列范围内有消耗的行；不补"配置即可见"默认行；无表头无列宽（天然适配 320）。

## 6. 交互与可访问性

- Pill：`role=button`、`tabIndex=0`、Enter/Space、`aria-expanded`、完整 aria-label。
- Panel：`role=dialog`；tab 用 `role=tablist/tab`，范围选择器用 `role=tablist`；键盘可完成全部切换。
- Segmented：每项 `role=tab`、`aria-selected`，roving tabindex；←/→/Home/End 移动，Enter/Space 选择。
- Toggle：`role=switch`、`aria-checked`；Space/Enter 切换；关闭后不改变焦点位置。
- 关闭入口必须有两个：右上角 `×`、点击面板外部；`×` 在 P2/P3 两个 tab 都常驻，不因切换隐藏；Esc 不处理；关闭后尽力归还焦点。
- tooltip（`ⓘ`）：`aria-describedby` 关联；hover、focus、触屏点按都可展示；Esc/失焦/滚动/resize/点击外部关闭；使用独立 `Tooltip` fixed 浮层，不随面板裁剪；header 支持范围与 `真实 Tokens` 说明两个触发点均默认向上、中心对齐按钮；P3 不显示支持范围图标。
- header `ⓘ` / `⟳` / `×` / `⤓` 的点击区均 22×22；行内 `ⓘ` 20×20 命中区；图标本身 12–14px，焦点环 2px。
- 刷新、保存、导出、检查更新结果用 `aria-live=polite`；错误用 `role=alert`。
- 语言：不提供 P3 语言切换；所有用户可见文案通过 `ctx.locale` 读取 DSH 当前语言（zh/en），跟随宿主自动切换；缺失词条回退英文或中文基线，不混排。
- 对比度正文 ≥4.5:1；预算状态不只靠颜色。
- i18n 使用 `token-dash` 命名空间；`zh` / `en` 词条用占位符拼装，不拼整句；跟随 DSH locale，不提供 P3 语言开关。

### 7.1 格式规则

| 类型 | 规则 |
|---|---|
| Tokens | `<1k` 整数；`1k–999.9k` 1 位小数；`≥1M` 1 位小数；去掉末尾 `.0`；示例 `999` / `1.08k` / `319.4M` |
| 金额 | 2 位小数，带币种符号；CNY `¥12.68`、USD `$19.00`；不跨币种合计 |
| 百分比 | 1 位小数，整数时去掉 `.0`；最大显示 `999%`；无分母显示 `--`；超支仍显示实际值 |
| 时间 | 本地 `HH:mm`；价格表 `YYYY-MM-DD HH:mm`；stale 后缀 `~` |
| 0 值 | 按已知币种分行显示 `¥0.00` / `$0.00`；无已知币种显示 `¥0.00` |

### 7.2 预算输入

- 允许空值（保存为 `0`，表示未设置）或 `>= 0` 的十进制数，不接受负数、科学计数法、货币符号；未填写时输入框显示默认 `100`（provider 币种），一旦保存即按保存值计算。
- 输入中不格式化；失焦/Enter 后保存并格式化为 2 位小数。
- 非法值：红边 + 行内 `请输入 0 或正数`，不提交，不覆盖旧预算。
- 保存失败：红边 + `保存失败，请重试`，保留输入；成功短暂显示 `已保存`。

## 8. 响应式与溢出

- 面板宽 `min(320px, calc(100vw - 16px))`；贴近窗口右缘时向左翻转，禁止页面横向滚动。
- 最大高 `70vh`；内部滚动；滚动条使用宿主 `--dsh-scrollbar-*`。
- provider / 模型名称单行截断 `text-overflow:ellipsis`；金额、百分比、币种不截断。
- 价格链接同一行；面板窄于 320 时该行允许横向滚动，隐藏滚动条，不换行。
- tooltip 最大宽 220px；默认向上，上方空间不足时向下翻转；右侧不足时向左对齐，不超出面板。
- 长错误文案最多 2 行；超出截断，完整内容放 title/aria-label。

- 不做"查看全部"/独立明细页/分页（BND-02）。
