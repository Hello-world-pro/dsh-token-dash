## 1. 定位与信息层级

| 层 | 回答的问题 | 只放什么 |
|---|---|---|
| P1 Pill | 现在怎样？ | 当前 provider 的模式、预算 %、今日、余额（订阅为窗口 %） |
| P2 用量 tab | 钱花在哪（范围）？ | 固定区（本月预算/订阅）+ 范围区（两格卡 + 明细行卡片） |
| P3 设置 tab | 怎么配？ | 预算、显示、日志、价格链接、更新 |

不重复原则：同一事实只在一个层级承担"主展示"；下层补增量，不原样复读。v2 起 P2/P3 收进同一浮层的 `用量 / 设置` 双 tab（用量在前，默认）。

| 信息 | P1 | P2 用量 | P3 设置 |
|---|---|---|---|
| 当前 provider 名称 | 否（只有模式徽标） | 是（组行） | 是 |
| 预算 % / 已用总额 | % | % + 迷你条 + 已用/总额 | 输入总额 |
| 今日消耗 | 是 | 否（范围卡替代"今日"概念；当天范围即今日） | 否 |
| 账户余额 | 是（开关控制） | 是（固定区预算行右端） | 开关 |
| 范围费用 / Tokens | 否 | 两格卡 + 明细（范围） | 否 |
| 按模型明细 | 否 | 行卡片（范围） | 否 |
| 订阅窗口 | 是（当前） | 固定区（全部，QuotaBlock） | 同款 QuotaBlock |

| 行高 / 间距 | 信息行 py 6px；组间 gap 10px；区内行间 gap 2px；面板 padding 12 |
| 分隔线 | 1px `--dsw-alias-border-l2`、左右缩进 8px、上下 margin 6px |
| tooltip | 背景 `--dsw-alias-tooltip-bg`、文字 `--dsw-alias-toast-label`、11px、最大宽 220px；位置自动翻转，不超出面板 |
| segmented | **cc-switch 胶囊同款、主题 token 化**：容器高 28、`p-[2px]`、圆角 8、轨道 `--dsw-alias-bg-module-platform`；子项 `flex:1`、高 24、圆角 6、11px/500、`px-2`；选中 `--dsw-alias-button-elevated-fill` + `--dsw-shadow-lv1`、文字 `--dsw-alias-label-primary`；未选中 `--dsw-alias-label-secondary`、hover `--dsw-alias-interactive-bg-hover`；150ms 颜色过渡，不做滑块/下划线 |
| segmented 宽度 | 顶部 `用量/设置` 与范围 `当天/7天/30天/全部` 均撑满可用宽、子项等分；P3 刷新间隔同样式、容器 224 宽；不按文字长度跳宽 |
| 圆角 | Pill 999；卡片 10；浮层 12；控件 6 |
| 主题 | 跟随宿主 CSS 变量；暗色由 `body[data-ds-dark-theme]` 切换；必须给回退值；**不写死白底/黑字** |
| 焦点 | `outline: 2px solid var(--dsw-focus-ring-color, var(--dsw-alias-state-business-primary))`；offset 2px；Tab 顺序 = 视觉顺序 |
| 动效 | 非必要不加；`prefers-reduced-motion` 下关闭 |

预算状态不能只靠颜色：百分比数字 + 状态色 + 文案共同表达。

## 3. P1 Pill（v2.21 不变）

```text
API    [API] 预算 25.4% · 今日 ¥11.37 · 余额 ¥8.74⌃
订阅   [订阅] 5h 42% · 周 18%⌃
```

- 两处槽位：首页工作区行；会话活动行左侧。都不撑开输入框。
- 只画 API / 订阅两态；判定不了默认 `[API]`；不显示 provider 名（hover title / aria-label 兜底）；无任何 provider 时显示 `[API] --`，不隐藏 Pill。
- API 段：预算 %（未设置显示"未设置"）· 今日 · 余额；金额按 provider 币种。
- 订阅段：5h/周窗口 + 重置时间；百分比是账户套餐，不拆单对话。
- 预算色：<80% 主色、80–100% 橙、≥100% 红；无数据 `--`，过期加 `~`。
- 尺寸：高 24、圆角 999、水平 padding 8、段间距 6；Enter/Space 展开，`aria-expanded` 同步。
- 加载：保留上次值；无上次值时预算/窗口 `--`，不显示 0%。
- 刷新失败/无 provider：显示 `[API] --` 或 `[订阅] --`，不隐藏 Pill；不弹出 toast。
- stale：上次成功超过 2 个刷新周期，数值后加 `~`；颜色不变。

### 4.1 结构

│ 用量 · 设置（胶囊）          ⓘ  ⟳  ×           │
├─ 固定区 · section ─────────────────────────────┤
│ 本月预算（已检测 2）                           │
│ DeepSeek   25% ▓▓░   ¥12.68/¥50.00   余额 ¥8.74│
│ 订阅套餐（账户级，已检测 2）              ⟳    │
│ GLM Coding   5h 42% ▓▓░   周 18% ░   14:05 重置│
│ Kimi Coding  5h 30% ▓▓░   周 12% ░   15:20 重置│
├─ 范围 ─────────────────────────────────────────┤
│ [当天|7天|30天|全部]（胶囊）                   │
├─ 范围区 · section ─────────────────────────────┤
│ 总费用 tile：¥12.68 / $19.00                   │
│ 真实 Tokens tile：319.4M（入 1.88M / 出 1.12M）│
│ DeepSeek                                       │

│ Qwen（百炼）                                   │

> 固定区所有条形都是同一个 MiniBar：48×4，轨道灰，填充主蓝；预算、5h、周窗口不换色、不变长。

### 4.2 固定区（不随范围变）

- 固定区整体一块 **section 底框**（低对比中性灰，圆角 10）；预算/订阅行在内部透明，不再逐行加卡框；两个小标都带动态 `(已检测 N)`。
- 只渲染 `summary.providers` 中实际存在的 API/订阅 provider；某区为 0 时隐藏该区，不显示空标题。
- 固定区所有条统一用一个 **MiniBar**：48×4、圆角满、轨道灰、填充主蓝；预算 % 一条、订阅每个窗口各一条；同一行多条也全部同规格，不做粗细/长短/颜色变体。
- **本月预算**：每 API provider 一行——`名称（13px）| %（11px）| MiniBar（48×4）| 已用/总额（11px）| 余额（右端，11px）`；百分比和条放在金额前，先看风险再看明细；超支红；无预算"预算未设置"+ 满格中性条；余额为账户余额（#31 定案：P2 恒显示，不受 P1 开关影响；Qwen 等不支持显示"—"）。
- **订阅套餐（账户级）**：每订阅 provider 一行 QuotaBlock 网格（`5h 42% ▓▓░ · 周 18% ░ · 14:05 重置`，三列：文字 11px | 迷你条 48×4 | 重置 10.5px）；标题行右侧只放 `⟳` 图标按钮（只重查订阅）；空窗口"套餐查询失败"。
- 订阅区 `⟳` 为 14px `RefreshCw` 图标、20×20 点击区、默认蓝按钮底、无文字；`aria-label="重新检测订阅配额"`，hover/focus 显示同名 tooltip；点击后图标旋转并禁用，不显示“检测中…”文字。
- 标题栏 `⟳` 是全局刷新（`/summary` + `/usage`），订阅区 `⟳` 是局部刷新；两者同图标，靠位置和 tooltip 区分，不靠文字。
- 固定区与范围区用 1px 分隔线分离；文案带"本月"防口径混读。
- P2 不显示底部“本机估算 / 刷新时间”底注；刷新状态只由标题栏 `⟳`（进行中禁用）表达。
- 标题栏固定 `ⓘ` 支持范围 + `⟳` 刷新 + `×` 关闭：`⟳` 重新拉取 `/summary`（固定区）与 `/usage`（范围区，带当前 range），进行中禁用；`×` 必须始终可见，点击关闭浮层。
- `ⓘ` 只在 P2 用量 tab 出现，位于 `⟳` 左侧；12px 图标、20×20 点击区、默认蓝按钮底（同 §2 按钮）；hover / focus / 触屏点按显示 tooltip：
  `目前支持 DeepSeek / Kimi / GLM / OpenRouter / Qwen API Key`
- tooltip 最大宽 220px、11px、两行内换行；不占常驻行，不改变头部高度；键盘可聚焦，`aria-describedby` 关联。

### 4.3 范围区（随范围变）

- 范围选择器就是顶部 tab 同款 **segmented 胶囊**：`当天 / 近7天 / 近30天 / 全部`，默认当天，本地记忆；尺寸和主题 token 见 §2；不是普通 tab / 下划线。
- 范围区整体一块 **section 底框**；两格统计卡用更深一层的 **tile 底框**（`color-mix(in srgb, var(--dsw-alias-label-primary) 4%, transparent)`），明细行保持透明，只靠间距和 hover 区分。
- **两格卡**：总费用（多币种分行）+ 真实 Tokens（detail：入/出）；只统计范围内有消耗的 provider/model；无消耗 `¥0.00`。
- **明细行卡片**（合并原费用表+用量表）：provider 组行（13px semibold）→ 模型行（名称左 + 费用右）→ 用量副行（三列网格）。
  - 费用是主比较指标：模型行右侧右对齐，`tabular-nums`；`未定价` 用 muted，近似价加 `≈`。
  - 模型用量移到下一行，用三列网格而不是点分隔：`Tokens 319.4M ⓘ` / `请求 1.08k` / `命中 99.4%`；网格 `minmax(0,1fr) auto auto`、列间距 8px，第 2/3 列右对齐；`Tokens` / `请求` / `命中` 为 9.5px muted 标签，数值 10.5px / 600 `tabular-nums`；`ⓘ` 紧跟 Tokens 数值，tooltip：`输入 1.88M · 缓存 316.39M · 输出 1.12M`。
  - 订阅 provider 不显示费用（右侧留空），用量仍保留；API 费用按 provider 币种，不跨币种。
  - 只列范围内有消耗的行；不补"配置即可见"默认行；无表头无列宽（天然适配 320）。

### 4.4 P2 状态

| 状态 | 表现 |
|---|---|
| 初次加载 | 固定区/范围区显示 2–3 行 muted 占位，不显示 0 值；不使用 spinner 占满面板 |
| 刷新中 | 保留旧数据；`⟳` 旋转并禁用；不遮挡内容 |
| 全量刷新失败 | 保留旧数据；头部下方 1 行 error strip：`刷新失败，保留上次数据` + `重试`；11px error 色 |
| `/usage` 局部失败 | 固定区保留；范围区替换为 `范围数据加载失败` + `重试`；不把旧范围数据当新数据 |
| 无 provider | 固定区隐藏；显示 `未检测到已配置供应商` |
| 无消耗 | 两格卡按已知币种显示 0；明细不渲染 |
| stale | 超过 2 个刷新周期未成功：`⟳` 加 4px amber 点，tooltip `数据可能过期`；不新增底注 |

## 6. 交互与可访问性

- Pill：`role=button`、`tabIndex=0`、Enter/Space、`aria-expanded`、完整 aria-label。
- Panel：`role=dialog`；tab 用 `role=tablist/tab`，范围选择器用 `role=tablist`；键盘可完成全部切换。
- Segmented：每项 `role=tab`、`aria-selected`，roving tabindex；←/→/Home/End 移动，Enter/Space 选择。
- Toggle：`role=switch`、`aria-checked`；Space/Enter 切换；关闭后不改变焦点位置。
- 关闭入口必须有两个：右上角 `×`、点击面板外部；`×` 在 P2/P3 两个 tab 都常驻，不因切换隐藏；Esc 不处理；关闭后尽力归还焦点。
- tooltip（`ⓘ`）：`aria-describedby` 关联；hover、focus、触屏点按都可展示；Esc/失焦关闭；支持范围 tooltip 只在 P2 头部，P3 不显示。
- `ⓘ` / `⟳` / `×` / `⤓` 的点击区均 ≥20×20；图标本身 12–14px，焦点环 2px。
- 刷新、保存、导出、检查更新结果用 `aria-live=polite`；错误用 `role=alert`。
- 对比度正文 ≥4.5:1；预算状态不只靠颜色。
- i18n 预留 `zh` / `en`，命名空间 `token-dash.*`；用占位符拼装，不拼整句。

### 7.1 格式规则

| 类型 | 规则 |
|---|---|
| Tokens | `<1k` 整数；`1k–999.9k` 1 位小数；`≥1M` 1 位小数；去掉末尾 `.0`；示例 `999` / `1.08k` / `319.4M` |
| 金额 | 2 位小数，带币种符号；CNY `¥12.68`、USD `$19.00`；不跨币种合计 |
| 百分比 | 1 位小数，整数时去掉 `.0`；最大显示 `999%`；无分母显示 `--`；超支仍显示实际值 |
| 时间 | 本地 `HH:mm`；价格表日期 `YYYY-MM-DD`；stale 后缀 `~` |
| 0 值 | 按已知币种分行显示 `¥0.00` / `$0.00`；无已知币种显示 `¥0.00` |

### 7.2 预算输入

- 允许空值（删除预算）或 `>= 0` 的十进制数，不接受负数、科学计数法、货币符号。
- 输入中不格式化；失焦/Enter 后保存并格式化为 2 位小数。
- 非法值：红边 + 行内 `请输入 0 或正数`，不提交，不覆盖旧预算。
- 保存失败：红边 + `保存失败，请重试`，保留输入；成功短暂显示 `已保存`。

## 8. 响应式与溢出

- 面板宽 `min(320px, calc(100vw - 16px))`；贴近窗口右缘时向左翻转，禁止页面横向滚动。
- 最大高 `70vh`；内部滚动；滚动条使用宿主 `--dsh-scrollbar-*`。
- provider / 模型名称单行截断 `text-overflow:ellipsis`；金额、百分比、币种不截断。
- 价格链接同一行；面板窄于 320 时该行允许横向滚动，隐藏滚动条，不换行。
- tooltip 最大宽 220px；下方空间不足时向上翻转，右侧不足时向左对齐，不超出面板。
- 长错误文案最多 2 行；超出截断，完整内容放 title/aria-label。
