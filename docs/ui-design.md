## 1. 定位与信息层级

| 层 | 回答的问题 | 只放什么 |
|---|---|---|
| P1 Pill | 现在怎样？ | 当前 provider 的模式、预算 %、今日、余额（订阅为窗口 %） |
| P2 浮层 | 钱花在哪？ | API 卡（已用/总额/%/今日/余额）、订阅卡、按币种费用表、按模型用量表 |
| P3 设置 | 怎么配？ | 预算、显示、日志、价格链接、更新 |

不重复原则：同一事实只在一个层级承担“主展示”；下层补增量，不原样复读。

| 信息 | P1 | P2 | P3 |
|---|---|---|---|
| 当前 provider 名称 | 否（只有模式徽标） | 是 | 是 |
| 预算 % | 是 | 是 | 否 |
| 预算已用 / 总额 | 否 | 是 | 输入总额 |
| 今日消耗 | 是 | 是 | 否 |
| 账户余额 | 是 | 是 | 否 |
| 月度费用 / 用量 | 否 | 是 | 否 |
| 按模型明细 | 否 | 是 | 否 |
| 订阅窗口 | 是（当前） | 是（全部） | 模式与状态 |
| 刷新时间 | 否 | 是 | 否 |

## 2. 全局视觉

| 项 | 规格 |
|---|---|
| 主色 | `var(--dsw-alias-state-business-primary, #6ea8ff)` |
| 警告 / 超支 | `#f0a020` / `#e05a5a` |
| 进度轨道 | `rgba(128,128,128,.25)`；中性填充 `rgba(128,128,128,.45)` |
| 字体 | 12px 基准；标题 13px / 600；数字 `font-variant-numeric: tabular-nums` |
| 圆角 | Pill 999；卡片 10；浮层 12；进度条 3 |
| 间距 | 浮层 padding 12；卡片 padding 12；行间距 8；区块间距 10–12 |
| 主题 | 跟随宿主 CSS 变量，必须给回退值；不写死亮 / 暗 |
| 动效 | 非必要不加；`prefers-reduced-motion` 下关闭 |

预算状态不能只靠颜色：百分比数字 + 状态色 + 文案共同表达。

## 3. P1 Pill

```text
API    [API] 预算 25.4% · 今日 ¥11.37 · 余额 ¥8.74⌃
订阅   [订阅] 5h 42% · 周 18%⌃
```

- 两处槽位：首页工作区行；会话活动行左侧。都不撑开输入框。
- 只画 API / 订阅两态；判定不了默认 `[API]`；不显示 provider 名（hover title / aria-label 兜底）。
- API 段：预算 %（未设置显示“未设置”）· 今日 · 余额；金额按 provider 币种。
- 订阅段：5h/周窗口 + 重置时间；百分比是账户套餐，不拆单对话。
- 预算色：<80% 主色、80–100% 橙、≥100% 红；无数据 `--`，过期加 `~`。
- 尺寸：高 24、圆角 999、水平 padding 8、段间距 6；Enter/Space 展开，`aria-expanded` 同步。

## 4. P2 浮层

### 4.1 结构

```text
Token 看板                                     刷新  设置  关闭
自动侦测 API Key 类型：DeepSeek / Kimi / GLM / OpenRouter / Qwen
API 按量（已检测 1）                                  刚刚
  [DeepSeek  预算 ¥12.68 / ¥50.00 · 25.4%  今日 ¥11.37  余额 ¥8.74]
  [======--------------------------------------------------]
API 费用明细 / 本月                            DSH 本机估算
  CNY 合计 ¥12.68
  模型                          占比        费用
  DeepSeek / DeepSeek-V4.1-Flash 100.0%    ¥12.68
模型用量明细 / 本月                              合计 319.39M
  模型              请求     输入      命中      输出     命中率
  DeepSeek / DeepSeek-V4.1-Flash 1088  1.88M  316.39M  1.12M  99.4%
```

- 卡片数量由 `summary.providers` 决定；无 API/订阅隐藏对应区，两者皆无显示空态。
- 顺序：当前 provider 第一，其余按今日消耗降序；超过 3 张 API 卡内部滚动。
- 浮层贴 pill 正上方：左对齐、间距 8px、允许遮挡；宽 380–600、最大高 70vh；无底栏。

### 4.2 区块头

- `API 按量（已检测 N）` + 新鲜度（`刚刚` / `N 分钟前`）。
- 下一行固定提示：`自动侦测 API Key 类型：DeepSeek / Kimi / GLM / OpenRouter / Qwen`。

### 4.3 API 卡

```text
DeepSeek        预算 ¥12.68 / ¥50.00 · 25.4%   今日 ¥11.37   余额 ¥8.74
[======--------------------------------------------------]
```

- provider 名 + 预算段（已用 / 总额 · %，状态色）+ 今日 + 余额；第二行进度条。
- 无预算：`预算 未设置` + 满格中性条，不显示百分比。
- 预算剩余不单独出数字；进度条宽度 = 已用比例（`percent`），不是剩余；余额是账户余额，与预算无关。
- provider 名超长省略（max 12em），`title` 兜底。

### 4.4 订阅卡

- 每 provider 一张：套餐名 + 5h/周/月窗口 + 重置时间；百分比只来自官方配额。
- 空窗口显示“套餐查询失败”；标题行右侧统一一个“重新检测”，只重查订阅。
- 订阅不进费用表；订阅 token 仍进用量表。

### 4.5 明细表

- 费用表：仅 API，按 CNY/USD 分组，列为 模型 / 占比 / 费用；每组独立合计，不跨币种。
- 用量表：全部 provider，列为 模型 / 请求 / 输入 / 命中 / 输出 / 命中率；合计为总 token。
- 模型列统一 `provider / model`；其他列不换行、不省略金额。
- 空态保留表头 + 占位行（`—` / `0` / `0.00M`），不整块消失。
- 表格横向滚动。

## 5. P3 设置

```text
← 返回  Token 看板                                  [关闭]
API 计费（已检测 N）
  [DeepSeek         月度预算 [ 50.00 ]  CNY]
订阅计费（已检测 N）                        [重新检测]
  [GLM Coding  订阅套餐 v  5h 42% / 周 18%]
显示        刷新间隔 [1 分钟 v]      账户余额 [开]
日志        查看日志 [打开日志文件夹] [导出日志]
价格与版本  查看价格明细  DeepSeek | GLM | Kimi | OpenRouter | Qwen
            版本 X.Y.Z                          [检查更新]
```

- 五区：API 计费 / 订阅计费 / 显示 / 日志 / 价格与版本；只列已配置 provider。
- API 行：provider + 月度预算 + 币种；预算按 provider 币种。
- 订阅行：模式 + 窗口；标题右侧一个“重新检测”。
- 日志：只有打开固定目录 + 导出脱敏 `.log`；不自动上传。
- 更新：发现新版本 → 确认 → 安装；成功显示实际版本“已更新到 X.Y.Z，重启 DSH 后生效”，失败显示原因并可复制命令；不静默更新。

## 6. 交互与可访问性

- Pill：`role=button`、`tabIndex=0`、Enter/Space、`aria-expanded`、完整 aria-label。
- Panel：`role=dialog`、焦点落标题；关闭走按钮或点击外部；Esc 不处理（D-15）；关闭后尽力归还焦点。
- Settings：每行唯一 label；错误 `aria-live=polite`；状态提示固定占位，避免浮层抖动。
- 对比度正文 ≥4.5:1；预算状态不只靠颜色。
- i18n 预留 `zh` / `en`，命名空间 `token-dash.*`；用占位符拼装，不拼整句。

## 7. 文案与空态

| 场景 | 文案 |
|---|---|
| 无预算 | `预算 未设置` |
| 预算段 | `预算 ¥12.68 / ¥50.00 · 25.4%` |
| 订阅失败 | `套餐查询失败` |
| 未定价 | `未定价`（近似价加 `≈`） |
| 空明细 | 保留表头 + `—` / `0` / `0.00M` 占位 |
| 更新成功 | `已更新到 X.Y.Z，重启 DSH 后生效` |
| 更新失败 | `更新失败（原因）` + 复制命令 |

金额按 provider 币种格式化；不跨币种合计；没有分母就不显示百分比。

## 8. 明确不做

- 不做 OS 悬浮窗、右下角挂件、显示位置设置。
- 不做趋势图、热力图、请求日志页、逐条明细。
- 不做价格编辑、汇率换算、自定义币种。
- 不做日志自动上传。
