## 页面与内容（框线图，本轮聚焦）

> 框线按等宽字体绘制（中文占 2 列）。为避免宽度歧义，图中用 `CNY` 代替 `¥`，实际 UI 仍显示 `¥`；设置入口是 P2 右上角“设置”，点击后整个浮层切换为 P3 视图，不跳转 DSH 设置页。

### P1 底栏 Pill

P1 不是统计面板，只回答“当前供应商离限额还有多远”。Token 已由 DSH 原生显示，这里不重复。

```text
API
┌────────────────────────────────────────────────────────────┐
│ [API] 预算 91.9% · 今日 ¥0.04 · 余额 ¥87.66⌃               │
└────────────────────────────────────────────────────────────┘

订阅
┌────────────────────────────────────────────────────────────┐
│ [订阅] 5h 42% · 周 18%⌃                                    │
└────────────────────────────────────────────────────────────┘
```

- 首页：位于输入框上方，与“默认工作区”同一行，Pill 紧随工作区选择器
- 会话：位于输入框下方，`1 轮 1 步` 活动行左侧
- 只支持 DeepSeek、Kimi、GLM、OpenRouter、Qwen；Qwen 仅按量 API，不显示订阅套餐；其他 provider 不显示
- P1 只画 `API` / `订阅` 两种样式；**判定不了或未识别时默认按 API 样式显示**（#38 词条统一：API / 订阅）
- API 样式也适用于 OpenRouter / Qwen（金额按币种变 USD/CNY）；无预算显示 `预算 未设置 · 今日 · 余额`，无余额显示 `余额 0.00`
- 左侧固定 `[API]` / `[订阅]` 徽标；**不显示 provider 名**（输入框右下角已有模型指示，去重；provider 名进 hover `title` 与 `aria-label` 兜底）（#36/#38 定案，2026-11-01）
- API：`预算` 固定第二位；有预算显示 `预算% · 今日消耗 · 余额`，无预算显示 `预算 未设置 · 今日消耗 · 余额`；今日消耗是当前 provider 的当日估算；金额按 provider 币种显示
- 订阅：显示 5h / 周两个窗口；只有一个窗口时显示该窗口 + 重置时间；百分比是**账户套餐**，不是单个对话用量
- 混合账号：P1 跟随当前对话/当前选中的 provider，不显示统一百分比；无法判定时用 `[API] --`

- 不显示今日/本月 Token；完整统计只在 P2
- 账户余额开关只控制 P1 余额段；P2 恒显示余额（2026-11-01 #31 修订）；"本月 Token"开关已删除（D-14）
- 末尾 `⌃` / `⌄` 表示可展开；hover 有背景；首次出现显示一次“点击查看 Token 看板”提示
- 状态色：API 预算 <80% 主色、80%~100% 橙、≥100% 红，百分比文字同步用状态色；订阅窗口按官方百分比原值着色，无数据 `--`，过期加 `~`

**布局规格**

| 项 | 值 |
|---|---|
| 容器 | 输入框左侧内联；高 24；圆角 999；水平内边距 8；段间距 6；不撑开输入框（#36 紧凑化） |
| 模式模板 | `api` / `subscription` 两种；`unknown` 默认复用 api 样式 |
| 徽标 | `[API]` / `[订阅]`；`unknown` 用 `[API]`；不显示 provider 名（hover `title` 兜底）（#36/#38 定案） |
| 分段宽度 | 徽标按内容；API 的 `预算` 固定第二位，今日第三位，余额第四位；订阅的套餐% 固定第二位；整条不强制均分 |

- 未检测到 API provider 时隐藏 API 区；未检测到订阅 provider 时隐藏订阅区；两者都无时显示空态“未检测到已配置供应商”。

| 区域 | 内容 | 备注 |
|---|---|---|
| 提示行 | 自动侦测 API Key 类型：DeepSeek / Kimi / GLM / OpenRouter / Qwen | 单行 11px muted，不交互；P2 固定展示全部 provider，不设范围筛选 |
| ① API 区（条件） | 每个 `api` provider 一张卡：预算%、今日、余额、独立进度条 | 无预算时进度条满格、中性色，只显示“未设置预算”；每张卡使用自己的币种（CNY/USD） |
| ② 订阅区（条件） | 每个订阅 provider 一张卡：5h / 周 / 月窗口、重置时间 | 仅 `subscription` 出现；百分比只来自官方配额 |
| ③ API 费用明细 | 仅 `api` provider + 模型：占比 + 费用；按币种分组 | 订阅 provider 不出现；占比在各币种内重算；不做跨币种合计 |
| ④ 模型用量明细 | 全部 provider + 模型：请求数、输入 / 命中 / 输出、命中率 | 订阅 token 仍保留；行序按 API/订阅分组或按 token 降序 |

- API 区按 provider 逐条渲染，不再只有一个全局预算卡；多个 provider 时纵向排列，卡片间距 8。
- 无预算 provider：进度条满格、中性色，只显示“未设置预算”；不参与预算告警，不显示任何百分比。
- 卡片顺序：当前对话 provider 第一，其余按今日消耗降序；超过 3 个时 API 区内部滚动。
- API 单一模式：隐藏订阅区，API 列表仍按 provider 渲染。
- 订阅单一模式：隐藏 API 区，只显示订阅卡与模型表；不再显示“预算%”。
- 混合模式：API 卡与订阅卡同时存在，但**不显示统一百分比**；费用表只统计 API，订阅行只出现在用量表。
- OpenRouter 使用 USD credits，不能与 CNY 预算或费用合并；费用表按 CNY / USD 分组，各组独立合计。
- P2 固定展示全部 provider，不提供 provider 筛选；P1 才跟随当前 provider。
- 费用表标题“API 费用明细（仅按量供应商）”，用量表标题“模型用量明细（全部供应商）”。
- 余额按 provider 分行，不再只有一个余额；余额列恒显示，账户余额开关只作用于 P1（#31 修订）。
- 数值加粗（600~700），标签常规字重；明细列对齐规则不变。
- P2 不设底部栏；刷新时间只保留 API 卡或订阅区的相对时间。

- P2 右上“设置”切到本视图；左上“← 返回”回到 P2，浮层不关闭、不改变位置。
- P3 用五个卡片分区：`API 计费` / `订阅计费` / `显示` / `日志` / `价格与版本`，不再是一堆无边界设置行。
- 标题栏：`← 返回` 与 `Token 看板` 左侧成组，`关闭` 右侧；不再把标题挤到右边。
- P3 只列已配置/已检测 provider；不预置 DeepSeek / GLM / Kimi / OpenRouter / Qwen 固定行。
- API 计费：每个 `api` provider 一张卡片，单行：provider 名 + 月度预算标签 + 输入框 + 币种；**不显示计费模式下拉**（#39，2026-11-01：大多数 provider 仅一个选项、无作用；计费模式完全依赖自动侦测，`billingModes` 数据层保留兼容、UI 不再暴露，手动覆盖入口随之下线）。
- 每张卡用自己的币种：DeepSeek / GLM / Kimi / Qwen 国内站为 CNY，OpenRouter 与 Qwen 国际站为 USD；预算输入也按该币种。
- 价格只读：DeepSeek / GLM / Kimi / Qwen 从项目内置 `catalog.json` 与社区价格表读取；OpenRouter 用 `/models` 目录；未收录显示“未定价”。
- `catalog.json` 带 `version / updatedAt / source`；随 npm 发布更新，用户 config 可覆盖，不在 P3 编辑。
- 不在 P3 维护模型单价；需要看价格时用“查看价格明细”跳官方页。
- 订阅计费：标题行右侧放一个“重新检测”，点击后统一检查所有订阅 provider；每个 provider 只显示模式、套餐窗口、重置时间，不显示预算与单价。
- 计费模式不再提供手动选择（#39）：默认按 provider 路由推断；`billingModes` 数据层保留（hide 过滤、订阅覆盖逻辑不动），UI 不暴露。

- 价格不在 P3 编辑；订阅 provider 不显示价格。
- 不做显示位置、子代理口径开关、汇率换算或自定义币种、图表配置。

### P4 页面跳转与状态

```text
首页 P1（输入框上方，工作区行）           ─┐
会话 P1（输入框下方，活动行左侧）         ─┴─点击─> P2 看板
P2 看板 ──设置──> P3 设置视图
P3 设置视图 ──返回──> P2 看板
P3 设置视图 ──查看价格明细──> 官方价格页（新窗口）
```

| 页面 | 入口 / 跳转 | 规则 |
|---|---|---|
| 首页 | 输入框上方工作区行 | 紧随“默认工作区”选择器右侧 |
| 会话 | 输入框下方活动行 | 在“1 轮 1 步”左侧；不挤模型选择器 |
| P1 → P2 | 点击整条 Pill / 键盘 Enter/Space | 浮层从 pill 正上方弹出（左对齐、间距 8px、允许遮挡） |
| P2 → P3 | 右上“设置” | 浮层内切换，不跳 DSH 设置页 |
| P3 → P2 | 左上“← 返回” | 保留浮层位置与宽度 |
| P2 / P3 → 关闭 | 右上“关闭” / Esc | 关闭后焦点归还 Pill |
| P3 → 价格页 | 底部“查看价格明细” | 新窗口，插件不请求 |

- P1 只分 API / 订阅两种；未知类型默认 API 样式。
- P2 固定展示全部 provider，不做范围筛选；API 与订阅分区。
- P3 只做设置，不做价格编辑；预算只属于 API provider。
- 首页 Pill 在工作区行，会话 Pill 在活动行；两处都在对话列内，右侧栏展开不跑位。
- P2 浮层从 pill 正上方弹出（左对齐 pill 左缘、间距 8px），允许遮挡输入框（#30 三次定案）。
- 设置是浮层内视图切换，不打开 DSH 设置页，也不依赖 `settings.section`。

- “查看价格明细”是一行超链接，四项分别打开（A-Z）：

| 厂商（A-Z） | 官方价格页 |
|---|---|
| DeepSeek | `https://api-docs.deepseek.com/quick_start/pricing` |
| GLM | `https://docs.bigmodel.cn/cn/guide/start/pricing` |
| Kimi | `https://platform.moonshot.cn/docs/pricing/chat` |
| OpenRouter | `https://openrouter.ai/models` |
| Qwen | `https://help.aliyun.com/zh/model-studio/billing-for-alibaba-cloud-model-studio` |

- Qwen 价格页使用百炼“模型调用计费”页，不再放不存在的深链。
- 用 `window.open(url, '_blank')` 打开新窗口；插件不请求、不缓存这些页面。
- P4 不涉及像素布局；入口在 P3 一行，间距 16。

### P5 可访问性与文案

**可访问性**

| 项 | 规则 |
|---|---|
| Pill | `role=button`、`tabIndex=0`；Enter / Space 展开；焦点环 2px 主色；`aria-expanded` 同步 |
| Pill 读屏 | 完整 `aria-label`：provider、模式、预算%或套餐窗口、今日、余额、币种；订阅百分比注明“账户套餐” |
| Panel | `role=dialog` + `aria-label`；Esc 关闭并归还焦点；打开时焦点落在标题 |
| Panel 结构 | API 区与订阅区各有标题；API 费用表按币种分组，表头包含币种 |
| Settings | 每个 provider 行有唯一 label；预算控件与币种绑定；错误用 `aria-live=polite` |
| 对比度 | 正文 ≥ 4.5:1，大字 ≥ 3:1；预算状态不能只靠颜色，必须有百分比/文字 |
| 动效 | `prefers-reduced-motion` 下关闭进度条过渡与数字滚动 |
| 触控 | 可点击区域 ≥ 28px，推荐 32px；Pill 整条可点；重新检测按钮 ≥ 28px |
| 键盘 | Tab 顺序：Pill → P2 头部按钮 → 内容 → P3 表单；Esc 关闭浮层 |

**国际化**

| 项 | 规则 |
|---|---|
| 语言 | `zh` / `en`；命名空间 `token-dash.*`；扁平 key |
| 占位符 | 文案不拼接，用 `{count}` / `{amount}` / `{currency}` |
| 数字 / 时间 | `Intl.NumberFormat` / `Intl.DateTimeFormat`；金额按 provider 币种格式化 |
| 币种 | CNY 显示 `¥`，USD 显示 `$`；不写死货币符号，不做汇率换算 |
| 套餐窗口 | `5h / week / month` 文案本地化；百分比与重置时间不拼接 |
| 复数 | 英文用 `Intl.PluralRules`，不手写 `s` |
| 缺失 key | 回退 `zh` 并只记一次日志，UI 不显示原始 key |
| 单位 | `M` 不翻译；`API Key`、`Provider` 保留原文 |

**关键文案**

| 场景 | 文案 |
|---|---|
| 预算未设置 | `未设置预算` |
| 本月无记录 | `本月暂无消耗` |
| 余额未配置 | `待配置` |
| 余额为 0 | `余额 0.00` |
| 未定价 | `未定价` / `部分未计价` |
| 订阅未配置 | `未配置订阅` |
| 套餐查询失败 | `套餐查询失败` |
| 数据过期 | `数据可能过期` |
| 路由失败 | `Token 数据不可用` + `重试` |
| 自动侦测提示 | `自动侦测 API Key 类型：DeepSeek / Kimi / GLM / OpenRouter / Qwen` |
| 日志导出 | `日志已导出` / `日志导出失败`；不提示上传成功 |
| 日志目录 | `已打开日志文件夹` / `无法打开，已复制路径` / web 显示 `复制日志路径` |
| 不支持 provider | `暂不支持该供应商` |

- 不显示“可用”“100% 可用”等无分母文案。
- 订阅窗口必须带“账户”语义，不能写成“本对话已用”。
